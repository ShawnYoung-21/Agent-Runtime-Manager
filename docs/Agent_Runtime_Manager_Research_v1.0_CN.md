# 4. Agent 生命周期感知研究

## 4.1 Process 层

能力：

判断 Agent 是否运行。

优点：

通用。

限制：

无法知道任务阶段。

------------------------------------------------------------------------

## 4.2 Terminal Output 层

能力：

通过 CLI 输出判断状态。

例如：

-   分析项目
-   修改文件
-   执行测试
-   完成任务

限制：

不同 Agent 格式不同。

------------------------------------------------------------------------

## 4.3 Hook / Event 层

能力：

如果 Agent 提供事件机制，可以获得更准确状态。

------------------------------------------------------------------------

## 4.4 API 层

理想方式：

Agent 提供状态 API。

目前生态没有统一标准。

------------------------------------------------------------------------

# 5. Windows 运行环境调研

重点：

Windows 11 + Laptop + Battery + Lid Closed。

关注：

## Power Management

系统提供应用级运行保障机制。

## Sleep

系统低功耗状态。

## Hibernate

保存状态后关闭。

## Modern Standby

现代 Windows 设备的重要低功耗模型。

项目影响：

需要理解合盖后的真实运行状态。
